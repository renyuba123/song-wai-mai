## Motorcycle and city ambience

These five files are derived from the high-quality MP3 previews on their
Freesound detail pages. The previews contain the same approved recordings;
Freesound requires an account to download the original uploads. Each detail
page lists the recording as CC0, so attribution is not required.

- `audio/motorcycle/start_a1.mp3` — "Motorcycle Start Engine.wav" by
  spenceomatic: https://freesound.org/people/spenceomatic/sounds/119774/
- `audio/motorcycle/drive_b1.mp3` — "Scooter engine loop" by
  Dmitry_mansurev64: https://freesound.org/people/Dmitry_mansurev64/sounds/747916/
- `audio/motorcycle/stop_c2_6_to_10.ogg` — seconds 6–10 of "Kawasaki Versys
  650cc '07 - Engine Work (Start / Stop)" by lapuafox, with short edge fades:
  https://freesound.org/people/lapuafox/sounds/815139/
- `audio/ambience/crowd_e2.mp3` — "Walla_In_Madrid_Spain" by
  SignatureSoundsOrg: https://freesound.org/people/SignatureSoundsOrg/sounds/869048/
- `audio/ambience/traffic_f2.mp3` — "URBAN TRAFFIC AMBIENCE 2.wav" by
  ListenTonyBoy: https://freesound.org/people/ListenTonyBoy/sounds/326270/

The source pages could not be reached from the build machine during the final
offline verification. Re-check the linked license pages before a public release.
